# E-Commerce Sales Analysis

## Objective
Analyze e-commerce transactions to identify revenue trends, top products, category performance, regional performance, and customer value.

## Tools
Python, Pandas, NumPy, Matplotlib, SQL, Power BI

## Dataset
A synthetic 1,200-order dataset was generated for portfolio practice. It contains order dates, customers, products, categories, regions, quantities, prices, discounts, sales and profit.

## Key Questions
- What are total sales and profit?
- How do sales change by month?
- Which categories and products perform best?
- Which regions generate the most revenue?
- What is the average order value?
- Which customers have the highest lifetime sales?

## Deliverables
- data/sales.csv
- notebooks/sales_analysis.py
- sql/analysis.sql

## Business Outcome
The analysis is designed to translate raw transaction data into actionable commercial insights such as product prioritization, regional focus, and customer targeting.
